# Лиса и ServerLisa

Исходный код клиента **Лиса 4.1.14** и сервера **ServerLisa 1.2.24** в одном проекте.

## Структура

- `client/` — приложение Лиса, обработка отчётов, автообновление и сборка клиента.
- `server/` — API ServerLisa, автоматизация Sigur и установка сервера.

Это исходники и ресурсы для сборки на Windows. Готовые EXE в архив не включены.

## Сборка на Windows

Требуется Python 3.12+ и доступ к пакетам Python. Команды выполняются отдельно в соответствующих папках:

```powershell
cd client
powershell -NoProfile -ExecutionPolicy Bypass -File .\build_client.ps1
```

```powershell
cd server
powershell -NoProfile -ExecutionPolicy Bypass -File .\install_server.ps1
```

`install_server.ps1` следует запускать в PowerShell от имени администратора. Он собирает сервер, заменяет установленную версию в `C:\AristocratServer`, настраивает автозапуск и проверяет `/ping`. Не запускайте отдельно `dist\ServerLisa.exe`, если сервер уже работает на порту 8000.

Подробности работы, сборки и обновления клиентов находятся в `client/README_CLIENT_4.1.14.md` и `server/README.md`.

## Настройка перед использованием в другой сети

В клиенте адреса сети зафиксированы в `client/client/constants.py`, а переходный адрес обновления — в `client/updates/version.json` и `client/publish_transition_update.ps1`. Эти адреса относятся к прежней локальной сети. Для другой сети измените их перед сборкой и публикацией обновления. Не публикуйте реальный файл базы и секреты: сервер читает строку подключения из переменной `DATABASE_URL`; по умолчанию использует локальный SQLite.

Сборка на живом компьютере с Sigur после объединения исходников здесь не запускалась.
